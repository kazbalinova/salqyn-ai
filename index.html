«Демода» белгісі бар функциялар қазір AI панельде жұмыс істейді. «Жоспарда» белгісі бар функциялар аппараттық прототип кезеңінде қосылады.

Қалай жұмыс істейді

Өлшейді, болжайды, басқарады

  1. Өлшейді

    Температура, ылғалдылық, есік ашылуы және өнім салмағы туралы деректер жиналады.

  2. Болжайды

    Модель әр өнімнің қалған сақталу мерзімін күнмен есептейді.

  3. Басқарады

    Барлық өнім қауіпсіз болатын ең жоғары температура қойылады, компрессор аз жұмыс істейді.

  4. Ескертеді

    «Сүтті бүгін ішіңіз» сияқты хабарлама келеді. Азық тасталмайды.

Сұрақтар

Жиі қойылатын сұрақтар

Салқын AI нақты өнім бе?

Бұл студенттік жоба. Қазір жұмыс істейтін нұсқасы веб-прототип: AI панельде тоңазытқышты модельдеуге болады. Аппараттық прототип келесі кезеңде жасалады.

Болжам қалай есептеледі?

Бұзылу жылдамдығы температурамен өседі: 10 °C жылы болса, шамамен үш есе тез. Модель осы заңдылықты, есік ашу санын және бөлме температурасын ескереді. Келесі кезеңде ол нақты сенсор деректерімен оқытылады.

Қауіпсіздік қалай сақталады?

Ет пен балықтың температуралық шегі қатаң: одан жоғары көтерілмейді. Электр үнемі қауіпсіздіктен маңызды емес.

Менің тоңазытқышыма қосуға бола ма?

Тіркелу кезінде өз тоңазытқышыңыздың маркасын, жасын және көлемін жазасыз. Болашақта сенсор жинағы арқылы қолданыстағы тоңазытқышқа қосу жоспарланған.

Деректерім қайда сақталады?

Демо нұсқада тіркелу деректері тек сіздің браузеріңізде сақталады, серверге жіберілмейді. Құпия сөз мүлде сақталмайды.

Электр шығыны (%), температураға қарай

Бұл жобаның бағдарламалық прототипі. Сақталу мерзімдері жалпы ұсынымдардан алынған шамамен мәндер, электр үнемі жылу алмасу моделінен есептелген. Нақты тоңазытқышта өлшенген деректер емес. Формула: бұзылу жылдамдығы = 3^((T − 4) / 10), қалған мерзім = L₄ / жылдамдық − сақталған күн.

Ақылды камера

Тоңазытқышта бар өнімнен не істеуге болады

Тоңазытқыш моделін таңдап, ішіндегі өнімдерді белгілеңіз. Үстіндегі камера оларды «көреді», ал AI аспаз таңғы ас, түскі ас, кешкі ас және десерт ұсынады.

Камера көрді

Тоңазытқыштағы өнімдер

Өнімді басып қосыңыз немесе алып тастаңыз. Тоңазытқышқа 16 өнімге дейін сияды.

Мерзімді бақылау

Әр өнім қанша күн сақталғанын көрсетіңіз. Қалған мерзім бөлме температурасы мен есік ашу санын ескереді (4 °C-та). Мерзімі өткен өнім рецептке қосылмайды.

    Үлгі код

    Температураны өлшеп, есіктің неше рет ашылғанын санайтын ESP32 бағдарламасының бастапқы нұсқасы. Нақты құрылғыда сынау керек.

    #include <OneWire.h>
#include <DallasTemperature.h>

#define ONE_WIRE_PIN 4   // DS18B20 деректер сымы
#define DOOR_PIN 14      // геркон, INPUT_PULLUP

OneWire oneWire(ONE_WIRE_PIN);
DallasTemperature sensors(&oneWire);
int doorOpens = 0;
bool lastOpen = false;

void setup() {
  Serial.begin(115200);
  pinMode(DOOR_PIN, INPUT_PULLUP);
  sensors.begin();
}

void loop() {
  bool open = digitalRead(DOOR_PIN) == HIGH;   // есік ашық
  if (open && !lastOpen) doorOpens++;
  lastOpen = open;

  sensors.requestTemperatures();
  float t = sensors.getTempCByIndex(0);
  Serial.printf("temp=%.1f door_opens=%d\n", t, doorOpens);
  delay(1000);
}

    Қалай тексереміз

    1. Деректерді жазу

    Тоңазытқыш ішіндегі температураны 24 сағат үздіксіз жазамыз. Есік ашылуын санап, температураның қалай көтерілетінін көреміз.

    2. Модельді түзету

    Есікті 0, 10, 20 рет ашып өлшейміз. Нәтижемен симулятордағы формуланың есік коэффициентін (0,0025) нақтылаймыз.

    3. Электр шығыны

    Электр есептегішпен тоңазытқышты 2, 4 және 6 °C-та бір-бірден екі тәулік жұмыс істетіп, нақты кВт·сағ шығынды салыстырамыз.
